Freight, Pallets & Dedicated Truck — Different Job, Different Rate

A dock-to-dock pallet run needs no loading labor from us, so it's priced off the driver-and-truck cost. A pallet run without dock or forklift access gets the labor-included rate. Truck-and-driver-only hire has no labor line at all. Same rule as everything else on this page: the rate matches the job.
